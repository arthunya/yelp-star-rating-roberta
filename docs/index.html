The question

A 3-star and a 4-star review can say almost the same thing. Can a model tell them apart?

Fine-tuned RoBERTa on Yelp reviews, then went hunting for the errors.

Project

Where does RoBERTa struggle?

Predicting 1 to 5 star Yelp ratings from review text. Tested on 5,000 held-out reviews (1,000 per star) against a TF-IDF + logistic regression baseline.

Arthunya Kanoklertwongse · MS Computer Science, Westcliff University
